# Pulso Vibranium (prototipo web)

Prototipo 3D estilo Roblox con las 5 ideas de "saltar → acumular energía cinética → liberar una onda de bloques".
Abre `index.html` en el navegador (usa Three.js r128 desde cdnjs).

| Tecla | Acción |
|---|---|
| WASD / flechas | Moverse |
| Espacio | Saltar (mantener = saltos seguidos) |
| E / Shift | Súper salto con la energía acumulada |
| 1-5 (menú) | Elegir modo · Esc: volver al menú |

Modos: Kinetic Arena, Vibranium Rush, Shockwave Tag, Heart of Wakanda, Pulse Defender.
En móvil aparecen un joystick y los botones Saltar / Pulso.

`game.html` es la misma página sin el esqueleto `<html>` (versión para publicar como Artifact).
